# 🌐 Personal Portfolio Website

## HTML & CSS Practice Project

A personal portfolio website built as a **learning and practice project while learning HTML and CSS**.

I created this project after watching free HTML & CSS tutorials and frontend development videos on YouTube. The main goal was to practice the concepts I was learning and understand how a complete portfolio website is structured and styled from scratch.

This project represents one of my early steps in my frontend development journey. 🚀

---

## 🌐 Live Demo

🔗 Live Website: https://fuyad254.github.io/Portfolio/


---

## 📸 Project Overview

This website is a personal portfolio-style landing page inspired by modern developer portfolio layouts.

It includes different sections to present personal information, services, projects, pricing plans, and social links.

The project was developed mainly to strengthen my understanding of **HTML structure, CSS styling, layouts, positioning, responsive design, and basic UI interactions**.

## 📑 Website Sections

### 🧭 1. Header & Navigation

The website includes a fixed navigation bar with links to different sections:

* Home
* About
* Services
* Portfolio
* Pricing
* Contact

A responsive hamburger menu is also implemented for smaller screen sizes.

---

### 👋 2. Hero Section

The hero section introduces the portfolio owner with:

* Personal introduction
* Name
* Short description
* Call-to-action button
* Profile/hero image

The main heading is:

> **This is me — Philip Gilbert**

---

### 👤 3. About Me

The About section contains:

* Personal information
* Short introduction
* About description
* Profile image
* View Full Details button

This section was created to practice building two-column layouts using CSS.

---

### 🛠️ 4. Offered Services

The services section displays multiple service cards.

Each service contains:

* Font Awesome icon
* Service title
* Description

Hover effects are added to make the cards more interactive.

---

### 📊 5. Statistics Section

A simple statistics section displays project-related numbers such as:

* Projects Completed
* Experience
* Happy Clients
* Other achievements

This section helped me practice creating horizontal layouts and styled statistics blocks.

---

### 💼 6. Portfolio Section

The portfolio section showcases featured projects using image cards.

Each project contains:

* Project image
* Project title
* Project category

Hover effects are applied to the project images to create a simple visual interaction.

---

### 💰 7. Pricing Section

The pricing section contains multiple pricing plans.

Each pricing card includes:

* Plan number
* Plan name
* Description
* Features
* Price
* Buy Now button

The cards also include hover animations and scaling effects.

---

### 🦶 8. Footer

The footer contains:

* About information
* Copyright information
* Newsletter subscription
* Social media icons
